# YangSoccer 기획서

> 게임 기획서 · v0.3 · 2026-11-17 (v0.2 초안을 문서로 옮기고 결정 사항을 반영)

PC와 모바일에서 하는 3D 11대11 축구 게임입니다. 선수를 직접 조작하는 정통 축구 게임의 손맛을 살리고, 실제 리그 라이선스 대신 가상 리그와 클럽 육성으로 승부합니다. (처음 가제는 PITCHLINE이었습니다.)

| 항목 | 내용 |
|---|---|
| 장르 | 축구 액션 · 스포츠 |
| 플랫폼 | 1단계 웹(PC·모바일) → 2단계 Unity PC |
| 시점 | 3D 방송 중계 시점 |
| 플레이 | 1인 vs AI → 로컬 2인 → 온라인 |
| 그래픽 | 스타일라이즈드 로우폴리 |
| 경기 시간 | 전후반 각 3~10분 (설정) |

## 01 방향성: 무엇을 만들고, 무엇을 만들지 않나

대형 축구 게임은 수백 명이 매년 만듭니다. 같은 방식으로 경쟁하면 이길 수 없으니, 작은 팀이 잘할 수 있는 부분에 집중합니다.

**만드는 것**

- 패스 한 번, 슛 한 번의 **조작감**을 최우선으로 다듬기
- 똑똑하게 움직이는 **팀 AI**: 빈 공간 침투, 압박, 커버
- 약팀을 맡아 키우는 **클럽 육성 모드**
- 모바일에서도 편한 **터치 조작**
- 팀·선수 이름과 유니폼을 바꾸는 **에디터**

**만들지 않는 것**

- 실제 구단·선수·리그의 이름, 엠블럼, 얼굴 (라이선스 문제)
- 실사 그래픽과 모션캡처 수준의 애니메이션
- 돈을 쓸수록 강해지는 선수 뽑기(가챠) 구조
- 초기 버전의 온라인 대전 (기반을 다진 뒤 추가)

**핵심 재미 세 가지**

1. **내가 만든 골**: 원투 패스, 스루패스, 감아차기로 직접 만들어 내는 득점 장면
2. **읽히는 상대**: AI가 납득할 만하게 움직여서, 이기면 내가 잘했다고 느껴지는 경기
3. **키우는 맛**: 무명 선수가 시즌을 거치며 에이스로 성장하는 과정

## 02 경기: 경기장과 경기 규칙

표준 경기장은 105×68m입니다. 포메이션(예: 홈 4-4-2, 원정 4-3-3)은 AI가 위치를 잡는 기준이 됩니다.

| 규칙 | 도입 시점 | 메모 |
|---|---|---|
| 골, 킥오프, 전후반, 타이머 | M1 | 경기가 처음부터 끝까지 돌아가는 최소 조건 |
| 스로인, 골킥, 코너킥 | M2 | 공이 라인을 넘으면 자동 재개 |
| 파울, 프리킥, 페널티킥 | M2 | 태클 각도와 타이밍으로 판정 |
| 오프사이드 | M2 | 설정에서 켜고 끌 수 있음 |
| 카드, 부상, 교체 | M4 | 클럽 육성 모드와 함께 |

## 03 조작: PC와 모바일

같은 동작을 두 플랫폼에 맞게 나눕니다. 슛은 버튼을 누르는 시간으로 파워를 정하고, 패스는 방향 입력에 가장 가까운 동료를 자동으로 찾습니다.

| 동작 | 키보드 | 게임패드 | 모바일 |
|---|---|---|---|
| 이동 | `W` `A` `S` `D` | 왼쪽 스틱 | 가상 조이스틱 |
| 짧은 패스 / 압박 | `J` | A | 패스 버튼 |
| 슛 (길게 누를수록 강하게) / 태클 | `K` | B | 슛 버튼 |
| 스루패스 | `L` | Y | 스루 버튼 |
| 로빙 패스 · 크로스 | `I` | X | 로빙 버튼 |
| 스프린트 | `Shift` | RT | 조이스틱을 바깥 점선까지 밀기 |
| 선수 전환 (수비 시) | `Space` | LB | 자동 전환 + 전환 버튼 |

모바일은 가로 화면입니다. 왼쪽 아래에 조이스틱, 오른쪽 아래 엄지가 닿는 부채꼴 안에 자주 쓰는 버튼을 모읍니다. 왼손잡이용 좌우 반전과 버튼 위치 옮기기를 지원합니다. 초보자용 "조작 보조"에서는 패스와 슛 방향을 자동으로 보정합니다.

## 04 선수: 능력치

능력치는 6개로 단순하게 시작합니다. 각 수치는 실제 물리값에 바로 연결되어, 숫자가 경기 안에서 체감되도록 합니다.

| 능력치 | 범위 | 경기에서 바뀌는 것 |
|---|---|---|
| 스피드 | 1–99 | 최고 속도(약 6.5~9.5 m/s)와 가속 |
| 드리블 | 1–99 | 공을 몸에 붙이는 거리, 방향 전환 시 공을 놓칠 확률 |
| 패스 | 1–99 | 패스 방향·세기의 오차 범위 |
| 슈팅 | 1–99 | 슛 최고 속도, 조준 오차, 감아차기 회전량 |
| 수비 | 1–99 | 태클 성공 판정 범위, 가로채기 반응 속도 |
| 체력 | 1–99 | 스프린트 지속 시간, 후반 능력치 감소 폭 |

골키퍼는 별도의 반응 능력치를 씁니다. 포지션(GK·DF·MF·FW)은 AI가 맡는 역할을 정합니다.

## 05 AI 설계

축구 게임의 품질은 AI가 결정합니다. 내가 조작하지 않는 21명이 어떻게 움직이느냐에 따라 게임이 살아 보이기도 하고 바보 같아 보이기도 합니다. 그래서 AI는 두 층으로 나눕니다.

**팀 AI · 어디에 있을까**

- 포메이션 기준 위치를 공의 위치에 따라 밀고 당김
- 공격 시 대형을 넓히고, 수비 시 좁히고 라인을 내림
- 팀 전술 설정: 점유 / 역습 / 강한 압박
- 슛·패스 길을 계산해 "빈 공간"에 선수를 보냄

**개인 AI · 무엇을 할까**

- **공 소유**: 패스, 드리블, 슛 중 기대값이 가장 높은 선택
- **공격 지원**: 패스 받을 각도 만들기, 침투
- **압박**: 가장 가까운 1~2명이 공 가진 선수에게 접근
- **마킹·커버**: 위험한 상대를 따라가고 뒷공간 지키기
- **복귀**: 역습을 당하면 기준 위치로 전력 질주

난이도는 AI의 판단 속도, 실수 확률, 판단할 때 살펴보는 선택지 수로 조절합니다.

## 07 기술 스택

**결정: 두 개의 프로젝트로 진행**

- **1단계 · 웹 버전** (`web/`): TypeScript + Three.js. 링크 하나로 PC와 모바일 브라우저에서 바로 플레이하며 재미를 검증합니다.
- **2단계 · Unity PC 버전** (`unity/`): 웹 버전에서 검증한 조작감, 공 물리, AI, 규칙을 바탕으로 Unity(C#)에서 새로 만드는 별도 프로젝트입니다. 애니메이션과 그래픽 품질을 높입니다.
- 두 프로젝트는 이 기획서(`docs/`)를 공유합니다. 웹 버전의 게임 로직(물리, AI, 규칙)은 화면 그리기 코드와 분리해 두어, Unity로 옮길 때 그대로 C#으로 바꿔 쓸 수 있게 합니다.

엔진을 고를 때 검토한 내용입니다.

| 선택지 | 장점 | 단점 |
|---|---|---|
| **TypeScript + Three.js** (1단계) | 브라우저에서 바로 실행되고 PC·모바일 동시 대응. 코드 중심이라 빠르게 반복하고 브라우저 자동 테스트도 가능 | 저사양 폰에서는 최적화 필요. 애니메이션 편집 도구가 적음 |
| **Unity** (2단계) | 모바일·PC 출시 경험이 가장 많이 쌓인 엔진. 축구 애니메이션 등 자료가 많음 | 에디터 중심 작업이라 코드만으로 다루기 어려움. 요금 정책 변동 |
| **Godot 4** | 무료 오픈소스이고 가벼움 | 모바일 3D 성능과 생태계가 상대적으로 작음 |
| **Unreal** | 그래픽 품질 최상 | 소규모 팀과 모바일에는 무겁고 과함 |

**웹 버전 구성 세부**

- **렌더링**: Three.js. 선수는 로우폴리 3D 모델이고, 움직임은 코드로 만든 절차적 애니메이션입니다.
- **공 물리**: 직접 구현. 중력, 공기 저항, 바운드, 회전에 의한 휘어짐(감아차기)만 다루면 되므로 범용 물리 엔진보다 가볍고 조절하기 쉽습니다.
- **게임 루프**: 60Hz 고정 시뮬레이션 + 렌더링 분리.
- **코드 구조**: 게임 로직(물리·AI·규칙)과 화면(Three.js)·입력을 분리. 로직은 브라우저 없이도 테스트할 수 있습니다.
- **해설**: 미리 녹음한 AI 음성 조각을 이어 붙여 재생합니다.
- **빌드·배포**: Vite로 빌드해 웹에 올립니다.
- **성능 목표**: PC 60fps, 중급 안드로이드폰 최소 30fps

## 08 로드맵

단계마다 "완료 기준"을 둡니다.

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **M0** 프로토타입 | 경기장, 선수 1명, 공 물리, 드리블·패스·슛 | 혼자 공을 몰고 가서 골을 넣는 것이 재미있다 |
| **M1** 5대5 경기 | 팀 AI 기본형, 선수 전환, 골·킥오프·점수·타이머, 빠른 경기 | AI 상대로 5분 경기가 끝까지 자연스럽게 진행된다 |
| **M2** 11대11 정식 경기 | 포메이션, 골키퍼 AI, 라인 아웃·코너·골킥·파울·오프사이드, 로컬 2인 | 처음 해보는 사람이 "축구 게임 같다"고 느낀다 |
| **M3** 모바일 대응 | 터치 조작, 보조 모드, 화면 UI, 성능 최적화 | 중급 안드로이드폰에서 30fps 이상으로 한 경기를 끝낼 수 있다 |
| **M4** 콘텐츠 | 가상 리그 32팀, 클럽 육성, 컵 대회, 에디터, 효과음과 해설 | 한 시즌을 처음부터 끝까지 플레이할 수 있다 |
| **M5** 웹 버전 공개 | 웹 버전을 링크로 공개 | PC와 폰에서 큰 버그 없이 플레이된다 |
| **U1** Unity PC 버전 | 별도 프로젝트. 웹 버전의 로직을 C#으로 옮기고 애니메이션과 그래픽을 새로 만듦 | 같은 11대11 경기가 Unity에서 더 자연스러운 움직임으로 돌아간다 |

## 09 위험 요소와 대응

| 위험 | 대응 |
|---|---|
| AI가 어색해서 게임 전체가 싸 보임 | AI에 가장 많은 시간을 씀. 자동 검사로 경기 통계를 확인 |
| 조작감이 둔함 | 입력 반응 속도와 공 터치감을 먼저 확정 |
| 모바일 성능 부족 | 모델 폴리곤 제한, 같은 모델 재사용, 그림자·관중 품질 옵션 |
| 기능이 계속 늘어남 | 로드맵 단계별 완료 기준을 지킴 |
| 라이선스·저작권 | 실제 구단·선수 이름, 엠블럼, 기존 게임의 UI와 이름을 쓰지 않음 |
